# Pollas 🐔

Un'avventura a Orta San Giulio.

Gioco 3D per iPhone 16 e iPhone 16 Pro Max (va anche su 16 Plus e 16 Pro), installabile come app dalla schermata Home tramite Safari.

## File

- `index.html` – il gioco
- `three.min.js` – motore 3D (three.js r128)
- `manifest.webmanifest` – nome, icona e schermo intero dell'app
- `sw.js` – fa funzionare il gioco anche senza internet
- `icons/` – icone dell'app e schermate di avvio per ogni iPhone 16

Per pubblicare una modifica: carica i file nuovi e cambia `pollas-v1` in `pollas-v2` (poi v3, ecc.) dentro `sw.js`.
